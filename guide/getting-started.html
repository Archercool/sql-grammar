什么是 SQL？ ​

SQL（Structured Query Language）是一种用于管理关系型数据库的标准化编程语言。

SQL 分类 ​

分类全称用途
DDLData Definition Language数据定义（创建、修改、删除数据库对象）
DMLData Manipulation Language数据操作（查询、插入、更新、删除数据）
DCLData Control Language数据控制（权限管理）
TCLTransaction Control Language事务控制

快速导航 ​

  • SELECT - 查询数据
  • INSERT - 插入数据
  • UPDATE - 更新数据
  • DELETE - 删除数据

使用搜索 ​

使用页面顶部的搜索框可以快速查找：

  • 语法名称（如 SELECT、JOIN）
  • 函数名称（如 COUNT、CONCAT）
  • 关键字（如 WHERE、ORDER BY）
