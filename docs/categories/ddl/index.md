# DDL - 数据定义语言

DDL（Data Definition Language）用于定义数据库结构。

## 包含内容

- **CREATE** - 创建数据库对象（表、索引、视图等）
- **ALTER** - 修改数据库对象结构
- **DROP** - 删除数据库对象
- **TRUNCATE** - 清空表数据

## 常用语句

| 语句 | 说明 |
|------|------|
| CREATE TABLE | 创建表 |
| ALTER TABLE | 修改表结构 |
| DROP TABLE | 删除表 |
| CREATE INDEX | 创建索引 |
| DROP INDEX | 删除索引 |
