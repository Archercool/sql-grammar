# SQL 入门指南

欢迎使用 SQL 语法参考手册！

## 什么是 SQL？

SQL（Structured Query Language）是一种用于管理关系型数据库的标准化编程语言。

## SQL 分类

| 分类 | 全称 | 用途 |
|------|------|------|
| DDL | Data Definition Language | 数据定义（创建、修改、删除数据库对象） |
| DML | Data Manipulation Language | 数据操作（查询、插入、更新、删除数据） |
| DCL | Data Control Language | 数据控制（权限管理） |
| TCL | Transaction Control Language | 事务控制 |
