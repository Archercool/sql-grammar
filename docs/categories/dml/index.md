# DML - 数据操作语言

DML（Data Manipulation Language）用于操作数据库中的数据。

## 包含内容

- **SELECT** - 查询数据
- **INSERT** - 插入数据
- **UPDATE** - 更新数据
- **DELETE** - 删除数据

## 常用语句

| 语句 | 说明 |
|------|------|
| SELECT | 查询数据 |
| INSERT | 插入新数据 |
| UPDATE | 修改现有数据 |
| DELETE | 删除数据 |
