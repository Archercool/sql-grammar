窗口函数 ​

窗口函数（Window Functions）可以对一组行进行计算，同时保留原始行的详细信息。

窗口函数与聚合函数的区别 ​

  • 聚合函数: 每组返回一行，减少行数
  • 窗口函数: 每行返回一个结果，不减少行数

常用窗口函数 ​

函数分类函数说明
序号函数ROW_NUMBER()排序序号（唯一）
序号函数RANK()排序序号（可重复）
序号函数DENSE_RANK()密集排序（可重复）
分布函数PERCENT_RANK()百分比排名
分布函数CUME_DIST()累积分布
前后函数LAG()往前第N行
前后函数LEAD()往后第N行
聚合函数SUM()累计 sum
聚合函数AVG()累计 avg
聚合函数COUNT()累计 count
聚合函数MAX()累计 max
聚合函数MIN()累计 min
首尾函数FIRST_VALUE()第一值
首尾函数LAST_VALUE()最后值

窗口函数语法 ​

sql
window_function(expression) OVER (
    [PARTITION BY column1, column2, ...]
    [ORDER BY column1 [ASC|DESC], column2 ...]
    [ROWS BETWEEN ... AND ...]
)

sql

    name,
    department,
    salary,
    ROW_NUMBER() OVER (ORDER BY salary DESC) AS row_num

综合示例 ​

sql
SELECT 
    department,
    name,
    salary,
    RANK() OVER (PARTITION BY department ORDER BY salary DESC) AS dept_rank,
    salary - LAG(salary, 1, 0) OVER (PARTITION BY department ORDER BY salary DESC) AS salary_diff,
    ROUND(AVG(salary) OVER (PARTITION BY department), 2) AS dept_avg_salary
FROM employees
ORDER BY department, salary DESC;
